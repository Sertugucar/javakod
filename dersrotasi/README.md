# DersRotası — Özel Ders

Özel dersleri tanıtan, HTML, CSS ve JavaScript ile hazırlanmış duyarlı bir web sitesi.

## Çalıştırma

Bu klasördeki `index.html` dosyasını tarayıcıda açın veya bir statik sunucu ile klasörü yayınlayın. Harici paket kurulumu gerekmez.

## İletişim formu

Form, kullanıcının kopyalayabileceği bir mesaj taslağı hazırlar. Bilgileri bir sunucuya göndermez; otomatik başvuru toplamak için ayrıca bir iletişim altyapısı gerekir.
